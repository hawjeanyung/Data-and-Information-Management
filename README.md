# 📚 Pustaka Chiew Bookstore Database System

## 📌 Overview

The **Pustaka Chiew Bookstore Database System** is a **SQL-based database project** developed for the **Data and Information Management** course. The system is designed to efficiently manage bookstore operations by organizing data related to books, customers, orders, suppliers, and inventory.

This project demonstrates the application of **relational database concepts**, **SQL queries**, and **data integrity constraints** in a real-world bookstore scenario.

## 🎯 Project Objectives

* Design a structured relational database for a bookstore system
* Apply data normalization to reduce redundancy
* Implement SQL queries for data manipulation and retrieval
* Ensure data integrity through primary and foreign key constraints
* Support effective management of bookstore information

## 🗂️ Database Scope

The database manages the following core entities:

* 📘 **Books**: Book details such as ISBN, title, author, price, and category
* 🧑‍💼 **Customers**: Customer information and contact details
* 🛒 **Orders**: Purchase records and transaction details
* 📦 **Suppliers**: Book suppliers and publisher information
* 🏬 **Inventory**: Stock levels and availability tracking

## 🛠️ Technologies Used

* 🗄️ **Database Language**: SQL
* 🧠 **Concepts Applied**:

  * Entity Relationship Diagram (ERD)
  * Normalization (1NF, 2NF, 3NF)
  * Primary & Foreign Keys
  * Constraints and Relationships
* 💻 **Platform**: MySQL / Oracle / SQL Server (depending on implementation)

## ⚙️ Database Design

* 📐 **ERD Design**: Clearly defines relationships between entities
* 🔑 **Primary Keys**: Uniquely identify records in each table
* 🔗 **Foreign Keys**: Maintain referential integrity across tables
* 🧩 **Constraints**: Enforce valid and consistent data entries

## 🧪 Sample SQL Operations

The system supports:

* 📝 `INSERT` – Add new records (books, customers, orders)
* 🔍 `SELECT` – Retrieve and filter bookstore data
* ✏️ `UPDATE` – Modify existing records
* 🗑️ `DELETE` – Remove records when necessary
* 📊 **Queries** involving joins, aggregation, and conditions
